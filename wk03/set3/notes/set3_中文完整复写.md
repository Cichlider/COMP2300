# Set3 模块化中文完整复写

## 模块 1：本周目标与总体脉络
- 主题从“组合逻辑”扩展到“顺序逻辑”，重点在“能够存储信息的电路”。
- 本周要点：状态与时钟、交叉耦合反相器、SR 锁存器、D 锁存器、D 触发器、寄存器与存储器、同步顺序电路、有限状态机（FSM）、同步与异步的对比、时序约束。
- 组合电路输出只依赖当前输入；顺序电路输出同时依赖当前输入与历史输入（状态）。

## 模块 2：记忆的本质与双稳态元件
- 存储 1 bit 的本质是“两个稳定状态”的双稳态元件。
- 交叉耦合反相器是最基本的双稳态元件：两个反相器首尾相连形成闭环。
- 分析结果：
  - 该结构有两个稳定态（Q=0 或 Q=1），能存 1 bit。
  - 上电时初始状态不可预测。
  - 仅靠它无法“受控地改变状态”，因此不够实用。

## 模块 3：SR 锁存器（NOR 结构）
- 用两个交叉耦合 NOR 门实现，增加 S（Set）与 R（Reset）输入。
- 行为总结（NOR 型 SR 锁存器）：
  - S=1, R=0 → 置位（Q=1）
  - S=0, R=1 → 复位（Q=0）
  - S=0, R=0 → 保持（Q 维持前值）
  - S=1, R=1 → 非法/矛盾（Q 与 Q' 同为 0，不符合互补）
- 结论：SR 锁存器可控，但“同时置位与复位”不合理，仍需改进。

## 模块 4：时间、时钟与离散化的时间模型
- 数字系统倾向于将时间离散化为“周期”，由时钟信号驱动。
- 时钟是周期方波：
  - 上升沿/下降沿是状态更新的重要时刻。
  - 时钟周期 T 与频率 f 关系：f = 1/T。
- 同步系统假设：状态只在时钟边沿改变，周期内保持稳定。

## 模块 5：D 锁存器（电平敏感）
- D 锁存器解决 SR 锁存器两大问题：
  - 避免 S=R=1 的尴尬情况。
  - 将“数据值”和“更新时间”分离（D 决定数据，CLK 决定时机）。
- 行为：
  - CLK=0：锁存器不透明（opaque），Q 保持。
  - CLK=1：锁存器透明（transparent），Q 跟随 D。
- D 锁存器是“电平触发/电平敏感”，不是边沿触发。

## 模块 6：D 触发器（边沿触发）
- D 触发器常由两个互补时钟控制的 D 锁存器（主-从结构）组成。
- 关键性质：
  - 在时钟上升沿（或下降沿）采样 D，随后 Q 保持该值。
  - 其他时间保持旧值，不透明。
- 常见别名：主从触发器、边沿触发触发器、正边沿触发器。

## 模块 7：寄存器与触发器变种
- 寄存器：多个触发器并联共享同一时钟，存储多位数据。
- 寄存器宽度 = 触发器数量（如 4-bit、32-bit、64-bit）。
- 典型变种：
  - 带使能（EN）的触发器：EN=1 才更新；EN=0 保持。
  - 时钟门控（clock gating）：用逻辑门控制时钟，但可能引入毛刺/延迟。
  - 带复位（RESET）与置位（SET）的触发器：可同步或异步复位。

## 模块 8：存储器（Memory）的结构与寻址
- 关键术语：
  - 地址（Address）：定位存储位置的编号。
  - 数据（Data）：该位置存放的信息。
  - 地址空间（Address space）：所有可寻址位置的集合。
  - 地址位数：log2(位置数)。
  - 地址性（Addressability）：每个地址存储的位数（常为 8 bit/1 byte）。
- 读写结构：
  - 行选择（wordline）由译码器控制。
  - 读出常借助多路复用器（MUX）。
  - 写入通过写使能（WE）与数据输入实现。
- 多端口存储器：多个端口可并行读写不同地址。
- 现代系统常为“字节寻址”。

## 模块 9：顺序逻辑、状态与同步/异步
- 状态是系统历史的“摘要”，决定未来行为。
- 实例：组合锁、饮料机、交通灯，都需要记忆过去输入。
- 异步系统：状态随事件发生而变化，难以统一时序控制。
- 同步系统：状态变化受时钟控制，易于分析与规模化设计。

## 模块 10：异步风险与同步规则
- 异步电路常有循环路径，可能产生竞态或振荡。
- 示例：环形振荡器、异步锁存器会出现不可预测行为。
- 同步顺序电路通过寄存器打断循环路径，保证稳定性。
- 组成规则（同步电路）：
  - 元件要么是寄存器要么是组合逻辑。
  - 至少有一个寄存器。
  - 所有寄存器共用同一时钟。
  - 每条循环路径包含至少一个寄存器。

## 模块 11：FSM 基础
- FSM：有限状态机，是离散时间的状态模型。
- 组成：
  - 状态寄存器（保存当前状态）
  - 下一状态逻辑
  - 输出逻辑
- Moore vs Mealy：
  - Moore：输出只依赖当前状态。
  - Mealy：输出依赖当前状态与输入。
- 状态寄存器必须用触发器而非锁存器，保证整个周期内稳定。

## 模块 12：FSM 表达与设计流程
- FSM 的表示：状态图、状态转移表、输出表、逻辑方程。
- 从电路“反推”FSM：由方程→表→编码→状态图。
- 设计流程（简化）：
  - 定义状态与输入/输出
  - 画状态图
  - 编码状态并构建转移表
  - 求下一状态/输出逻辑方程
  - 实现逻辑电路
- 状态编码策略：
  - 二进制编码：触发器数少，但组合逻辑可能复杂。
  - One-hot 编码：触发器数多，但逻辑更简单。

## 模块 13：顺序电路时序分析
- 三个核心参数：
  - t_pcq：时钟上升沿到 Q 稳定的延迟（clock-to-Q）。
  - t_setup：采样前必须稳定的时间。
  - t_hold：采样后必须保持稳定的时间。
- Aperture time = t_setup + t_hold。
- 现代触发器的 t_hold 常接近 0。
- 时钟周期公式：
  - T_c = t_pcq + t_pd(max) + t_setup
  - 其中 t_pd(max) 为组合逻辑最大传播延迟。
- 序列开销（sequencing overhead）：t_pcq + t_setup，会挤占“有效计算时间”。
