# Set 4 中文完整复写

## 模块 1：课程位置与抽象层次
- 已完成数字逻辑基础（组合逻辑与时序逻辑），这些是构建 CPU 的底层能力。
- 现在进入架构（ISA/Architecture）层，并逐步进入微体系结构（Microarchitecture）层。
- 抽象层次自下而上：电路/器件 → 逻辑结构 → ISA/微体系结构 → 程序与算法 → 问题。

## 模块 2：计算机系统与冯·诺依曼模型
- 计算机系统的关键资源：CPU、内存、输入/输出设备。
- 内存形成层次结构：寄存器（最快、容量小）→ SRAM → DRAM → 磁盘（慢但持久）。
- 冯·诺依曼模型（1946）：
  - 五大部件：内存、处理单元、输入、输出、控制单元。
  - 存储程序：指令和数据都存放在同一线性内存中。
  - 顺序执行：程序计数器（PC）指向当前/下一条指令，按顺序取指并执行，除非控制流改变。

## 模块 3：ISA 与微体系结构
- ISA（Instruction Set Architecture）是软件与硬件之间的接口：
  - 指令集合与二进制编码、语义定义、字长、寄存器数量、地址空间/地址可寻址性。
- 微体系结构是 ISA 的具体实现与组织方式：
  - 例如使用何种加法器（ripple-carry vs carry-lookahead）、多路复用器或三态缓冲等。
- 一个 ISA 可以对应多个微体系结构；ISA 变化慢、微体系结构变化快。
- 编译器需要 ISA 来把高级语言翻译成机器可执行的指令。

## 模块 4：常见 ISA 与指令/程序概念
- 课程中会接触：QuAC（教学 ISA）、MIPS、ARM、LC-3、x86-64。
- 程序是指令序列；指令是最小的可执行工作单元；指令集是所有可执行指令的集合。

## 模块 5：内存组织与地址体系
- 内存阵列由译码器选择字线、位线输出数据；可设计多端口内存实现多地址访问。
- 内存中比特按字节/字组织：
  - 地址空间：可唯一寻址的位置数量。
  - 地址可寻址性：每个地址存储的位数（如字节寻址/字寻址）。
- 字节寻址 vs 字寻址：
  - MIPS/ARM 为字节寻址；QuAC 可为字寻址。
- 大端/小端：字节在内存中的排列顺序不同。
  - 大端：高位字节在低地址；小端：低位字节在低地址。
- MAR/MDR：
  - 读：MAR ← 地址，内存数据进入 MDR。
  - 写：MAR ← 地址，MDR ← 数据，写使能后写回内存。
- 必须区分“地址”与“数据”。

## 模块 6：处理单元、ALU 与寄存器
- ALU 执行算术/逻辑操作；字长随 ISA：ARM/MIPS 为 32 位，QuAC 为 16 位。
- 寄存器文件：靠近 ALU 的高速小容量存储，用于保存中间结果。
- ARM 有 16 个寄存器（R0–R15）；MIPS 有 32 个；QuAC 有 8 个。
- 寄存器由触发器组成，支持同步写入与读出。

## 模块 7：I/O 设备与控制单元
- I/O 设备通过寄存器与 CPU 交互：
  - 键盘：KBDR（数据）、KBSR（状态）。
  - 显示器：DDR（数据）、DSR（状态）。
- 控制单元负责指令执行流程：
  - IR 保存当前指令。
  - PC 保存下一条指令地址。

## 模块 8：指令集基础与指令类型
- 指令有操作码（opcode）与操作数（operands）。
- 机器语言是二进制编码，汇编是人类可读形式。
- 三类指令：
  - 数据处理（ALU 运算）。
  - 数据移动（内存与寄存器之间）。
  - 控制流（分支/跳转）。
- 建筑状态（Architectural State）：寄存器、内存、PC 等对程序员可见的状态。

## 模块 9：ARM 数据处理指令与设计原则
- 示例：a = b + c − d 可用 ADD 与 SUB 完成。
- 设计原则：
  - 规则性简化硬件（统一指令格式）。
  - 小而快（寄存器文件越小越快）。
  - 折中设计（立即数需要特殊格式）。
  - 让常见情况更快（采用简单常用指令）。
- 立即数：无需额外访存，但受编码位宽限制（通常 8–12 位）。
- MOV 指令常用于寄存器初始化。
- ARM DP 格式字段：cond、op、funct（含 I、cmd、S 位）、Rn、Rd、Src2。
  - I=1 表示 Src2 为立即数；I=0 表示 Src2 为寄存器。
- 其他 DP 指令：AND、ORR、EOR、BIC、MVN。
- RISC vs CISC：RISC 指令少而简单，硬件简单、频率高；CISC 指令复杂、数量多。
- QuAC 也是 RISC 风格：固定宽度指令、少量寄存器、通过专门指令访问内存、支持条件执行。

## 模块 10：数据移动指令与寻址
- LDR/STR 用于寄存器与内存之间的数据移动。
- 基址+偏移寻址（Base + Offset）：
  - 地址 = 基址寄存器值 + 立即数偏移。
- LDR 结果写入寄存器；STR 将寄存器内容写入内存。
- 字节寻址内存一次仍可读/写完整字（例如 32 位）。

## 模块 11：条件执行与状态标志
- CPSR 保存条件标志位：N（负）、Z（零）、C（进位/借位）、V（溢出）。
- CMP 指令执行减法，仅更新标志不写结果。
- 指令后缀 S 可让算术指令更新标志位（如 ADDS）。
- 条件助记符（EQ/NE/MI/HS/LT 等）控制是否执行指令。
- QuAC 也支持条件执行，通过 cond 位与 Z 标志配合。

## 模块 12：控制流与分支
- 顺序执行：PC 在取指阶段更新。
  - 32 位字节寻址：PC = PC + 4。
  - 32 位字寻址：PC = PC + 1。
- 分支指令改变 PC：
  - B/BL 使用 imm24。
  - 目标地址计算：imm24 左移 2 位 → 符号扩展 → 加 PC+8。
- 分支术语：分支目标、条件、Taken/Not-Taken，分支预测。
- 高级结构映射：
  - if / if-else 通过 CMP + 条件分支或条件执行实现。
  - switch 可通过多次比较与条件执行实现。
- 条件执行减少分支，但可能导致无效取指；分支预测可缓解性能损失。

## 模块 13：指令周期与实现视角
- 指令周期常见阶段：取指、译码、计算地址、取操作数、执行、写回。
- 另一常用五阶段：取指、译码/读寄存器、执行、访存、写回。
- ISA 角度只关心从 AS 到 AS’ 的状态转移；微体系结构决定如何实现（单周期/多周期）。

## 模块 14：单周期 ARM 微体系结构
- 建筑状态元素：PC、指令存储器、寄存器文件（两读一写）、数据存储器。
- 读 R15 返回 PC+8；写 R15 需要正确处理。
- Datapath 负责数据通路，Control Unit 产生控制信号。
- 逐步支持的指令：LDR、STR、DP(立即数)、DP(寄存器)、Branch。
- Extend Block 根据 ImmSrc 产生零扩展/符号扩展立即数。
- 关键控制信号：RegWrite、MemWrite、MemtoReg、ALUSrc、ALUControl、ImmSrc、RegSrc、PCSrc。
- 条件执行需要在控制单元中“杀掉”不应更新状态的写使能。

## 模块 15：性能分析
- 执行时间：
  - Execution time = (#instructions) × CPI × clock period。
- CPI 与微体系结构有关；clock period 由关键路径决定。
- 单周期机的时钟周期由最慢指令决定，是其主要缺点之一。
