# COMP2300 Resource Repo

这个仓库面向正在修 `COMP2300 / COMP6300 / ENGN2219` 的同学，也面向以后会修这门课、想提前了解课程结构的同学。

它不是官方课程主页的替代品，更像一份按主题整理的资料入口：把 lab、练习题和部分历年考试材料放在一起，方便跟课、复习和回顾。

课程主页：
[COMP2300 course website](https://comp.anu.edu.au/courses/comp2300/)

## 课程核心信息

这门课主要分成两条线：

- 硬件部分：使用 `Digital` 从逻辑门、组合逻辑、时序逻辑一路搭到 CPU。
- 软件部分：学习 ARM 汇编，理解程序如何在底层被表示、执行和调试。

目前这份仓库对应的理解重点，仍然是这门课最核心的两件事：

- 从电路角度理解计算机是怎么“搭出来”的。
- 从汇编角度理解程序是怎么“跑起来”的。

## 本仓库能提供什么

你可以把这个仓库当成一个比较实用的课程资料导航：

- [comp2300-2026-lab-pack-1](./comp2300-2026-lab-pack-1/)：课程 lab pack 的入口链接。出于学术诚信考虑，这里不展开展示具体实验内容；如果你正在修课，请按课程要求在私有空间中使用。
- [set1](./set1/) 到 [set5](./set5/)、[set6](./set6/)：课程相关练习或资料目录。
- [set7.pdf](/Users/cichlidfish/COMP2300/set7.pdf) 和 [set8.pdf](/Users/cichlidfish/COMP2300/set8.pdf)：额外的练习材料。
- [pastexam](./pastexam/)：历年试卷、补考试卷、model midterm 和部分 marking notes，适合用来熟悉题型与复习节奏。

如果你是这学期正在上课的同学，这个仓库最有价值的地方通常是：

- 按顺序完成课程提供的 lab，建立从 `mux`、`adder`、`register` 到 `control unit`、`cpu` 的完整知识链条。
- 配合练习题和 past exam，看清考试更常考“电路推导”还是“ARM/执行过程分析”。
- 复习时把资料集中在一起，不用每次都重新到处翻找。

如果你是以后会修这门课的同学，这个仓库可以帮助你：

- 提前知道这门课前半段不是“泛泛讲硬件”，而是真的会让你自己搭电路、搭 CPU。
- 提前接触课程文件结构和常见组件命名，降低开学后的陌生感。
- 用 past exam 和 lab 目录先建立对课程难度和节奏的预期。

## 建议怎么用

- 正在修课：以官方 lab page、Ed 公告和 assessment 页面为准，这个仓库主要用于整理和辅助复习。
- 预习课程：先了解 lab pack 的整体结构，再看练习题和 past exam，会比较容易建立整体印象。
- 期中或期末复习：先顺着 lab 过一遍知识结构，再做 set 和 past exam，效果通常比只刷题更好。
