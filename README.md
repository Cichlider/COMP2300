# COMP2300 Resource Repo

`COMP2300 / COMP6300 / ENGN2219` 资料仓库，主要用于整理 lab、lecture set 和 past exam。

课程主页：
[COMP2300 course website](https://comp.anu.edu.au/courses/comp2300/)

## 课程内容

- 硬件部分：用 `Digital` 从基础电路一路搭到 CPU。
- 软件部分：学习 ARM 汇编与程序执行过程。

## 仓库结构

- [comp2300-2026-lab-pack-1](./comp2300-2026-lab-pack-1/)：课程 lab pack 入口链接，仅作索引使用；修课时请按要求在私有空间中使用。
- [set1](./set1/) 到 [set8](./set8/)、[set7.5_cache](./set7.5_cache/)：lecture set 与整理资料。
- [pastexam](./pastexam/)：历年试卷、补考试卷、model midterm 和 marking notes。
- [SETX_AGENT_WORKFLOW.md](./SETX_AGENT_WORKFLOW.md)：`setX` 资料整理流程说明。

每个 `setX` 目录通常包含：

- `setX.pdf`：原始课件。
- `raw/`：逐页提取文本。
- `notes/`：中文整理与可考知识点清单。
- `exam/`：练习卷、答案及对应 PDF。
